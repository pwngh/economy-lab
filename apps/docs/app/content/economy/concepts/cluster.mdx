One economy node handles one [netting session](/economy/concepts/session-netting/) at a time. The session exists to serialize a lane's work: one node applies a scope's movements, in order. Run several nodes and a new obligation appears. Every caller must send a given scope key (a world instance, a region shard) to the same node for the scope's life. Then exactly one lane ever accepts its movements.

## The router

<ClusterTopology />

`scopeRouter(nodes)` returns that assignment as a pure function. Each node's weight for a scope is a hash of the (node, scope) pair, and the scope belongs to the highest weight — rendezvous hashing.<Cite n={1} /> Every node computes the same answer from the same fixed list, with no ring state to coordinate. A membership change reassigns only the departed node's scopes, so everyone else's sessions stay sticky.

The router decides where _new epochs_ open, nothing more. An epoch is one settle-and-restart period of a scope's session; [session netting](/economy/concepts/session-netting/) owns the term. Live sessions on a moved scope finish through epoch rotation and the orphan sweep — assignment never strands money.

## The cluster node

`openClusterNode` is one construction for what a multi-node host would otherwise hand-wire. It binds the router to this node's identity, and it adds the store-backed shared reservation registry (`sharedReservations`), ownership-gated session opening, crash recovery, and the orphan sweep. The shared registry means a buyer cannot promise the same credits to sessions on two nodes.

```ts
import { openClusterNode } from '@pwngh/economy-lab/netting';

const node = openClusterNode(ports, {
  nodeId: 'econ-2',
  nodes: ['econ-1', 'econ-2', 'econ-3'],
  epochMaxAgeMs: 60_000,
  sweep: { settleOlderThanMs: 180_000 },
});

node.owns(scope); // does this node hold the scope?
const session = node.openSession(scope); // throws SESSION.MISROUTED if not
```

The ownership gate turns a routing mistake into a loud error instead of a forked session. `openSession` and `assertOwns` throw `SESSION.MISROUTED` when a scope's traffic reaches a node its assignment does not name. The error's `detail.owner` names the node the scope belongs to. The edge can redirect from there.

## The epoch-age law

Construction refuses a `sweep.settleOlderThanMs` under twice `epochMaxAgeMs`, with `CONFIG.INVALID`. The reasoning is mechanical. Every epoch on a live node rotates within `epochMaxAgeMs`, and a due rotation is only observed a sweep cadence later. Below that bound, the sweep could therefore settle an epoch a live node is still filling. At or above it, an unsettled session older than the bound can only belong to a dead node.

## Crashed nodes

A node that dies mid-epoch leaves sessions journaled but never settled. `sweepOrphans` (the worker runs it as the `orphans` sweep) enumerates them from the journal and reports each with its age. Settling an orphan moves money — it happens only with `settleOlderThanMs` set. The settle is the session's own idempotent finish, so racing a node that turns out to be alive never double-posts. `recover(sessionId)` is the targeted form: on failover, it finishes a specific crashed epoch's settle.

One repair stays manual on purpose. `reconcileReservations` rebuilds the shared registry's counters from the journal. It runs only as an operator action on a quiesced cluster, because a live node's in-flight movements would race the rebuild.
